# Persona Forge 人设生成器

SillyTavern（酒馆）第三方扩展：按固定的人设格式（name / background_story / appearance / personality / …）生成 user 人设。

## 功能

- 随机灵感：随机组合身份、性格、外貌、小习惯、小秘密、关系，填进关键词框
- AI 生成：用酒馆当前连接的模型，按人设格式把关键词扩写成完整设定
- 应用到当前人设：写进当前 Persona 的描述框
- 复制结果

## 安装

酒馆 → 扩展（积木图标）→ 安装扩展 → 填入本仓库的 GitHub 地址 → 安装。
安装后在扩展面板里能看到「Persona Forge 人设生成器」。

## 格式

字段完全按作者自己的人设模板（含 archetype、personality 的「词语概念: "行为说明"」写法）。NSFW_information 段可在面板里取消勾选。
